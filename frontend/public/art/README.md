# Tranh Tiên Linh Giới

Chỉ đặt tài nguyên do dự án sở hữu hoặc có quyền sử dụng. Không sao chép/hotlink tklgame.com.

| File                               | Kích thước       | Nội dung            |
| ---------------------------------- | ---------------- | ------------------- |
| bg-title.webp                      | 1920×1080        | Nền khởi động ngang |
| bg-title-portrait.webp             | 1080×1920        | Nền khởi động dọc   |
| logo.png                           | rộng khoảng 1200 | Logo trong suốt     |
| char-1.png, char-2.png, char-3.png | cao khoảng 1400  | Nhân vật cắt nền    |
| avatar-1.webp đến avatar-6.webp    | 512×512          | Avatar tròn         |

Mỗi ảnh nên dưới 500 KB, ưu tiên WebP. File có mặt được tự phát hiện khi build; dev server tự khởi động lại khi thêm/xóa file. Đường dẫn dùng BASE_URL nên chạy dưới /tien-linh-gioi/. File chưa có không được yêu cầu qua HTTP: dùng nền thủy mặc CSS và biểu tượng tự vẽ thay thế. Không cần tạo file rỗng giữ chỗ.
